synthesis as not_as

not_as

The function. Pure computation. Returns a number.

A not_as receives the input and returns a single number. Internally it can do anything — recursion, I/O, loops, network calls — but externally it is just a value contributed to the pipeline. It never calls another not_as directly. The connection is always through an as.

This separation is the entire point. The not_as owns the complexity of computation. The as owns the simplicity of connection. Neither crosses into the other's domain.

not_as has no position. not_as is the value of computation.
