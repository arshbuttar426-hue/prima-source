Constraint-first
Three primitives.
One rule. No hidden state.
Every system reduces to a choice of frame. Before any computation, someone decides what the input counts as. That choice is invisible — until you make the frame the architecture itself.
as

Frame

Pure position. What a value counts as. Carries no value, only judgment. The arrangement of frames is the design.

not_as

Constraint

The negative. What a value must not count as. Enforced the instant a frame is applied. Failure is dead air.

fn[n]

Atom

One computation, index-selected from a named space. Stateless, verifiable alone. The frame decides if it is seen.

Same atoms. Different frame. Different result. The something never changed — only what you counted it as.
Proven
Tested where it matters.
Web, Android, Python, browser — all reduced to frames and atoms. Zero dependencies. The frame swap is instantaneous: change the judgment, keep the computation, watch the output invert.
