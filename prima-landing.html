Move your cursor. The field reorganizes — nodes within reach become as, beyond it remain not_as. The boundary is the language.
Three primitives
as
Positive constraint
A value counts as X. The frame admits it. Connection forms, the node glows blue, the computation proceeds.
not_as
Negative constraint
A value absolutely does not count as Y. The frame rejects it. Orange, isolated, the pipeline goes silent.
fn[n]
Categorical computation
Work selected by index from a function space. Gold — the frontier where structure meets choice.
Not a framework. Not a syntax. A position held against a negation — and everything else is what survives between them.
