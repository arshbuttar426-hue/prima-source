Architecture

Everything is position or computation.

Every system reduces to two kinds of thing: the joint that connects, and the function that computes. No frameworks. No hidden state. No third primitive.

◉

as

The connective joint. Pure position. Carries no value. Determines whether a function adds, subtracts, or idles. The architecture is the arrangement of as nodes.

◼

not_as

The computational unit. Returns a number. Internals are free — loops, recursion, I/O. Externally it is only a value in an equation. Never calls another not_as directly.

⌬

All interconnections are + or −. No event bus, no dependency injection, no message queue. Debugging is linear trace. Modularity becomes free because the connections are arithmetic.
