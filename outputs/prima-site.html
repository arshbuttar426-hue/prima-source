Runtime

A self-contained C interpreter — v0.2.0

prima.c is a single-file C interpreter with zero external dependencies beyond the standard library. Build with cc -o prima prima.c -lm.

Four native capabilities: file I/O, regex pattern matching, pipe-to-pipe composition, and iteration. Three primitives preserved — as, not_as, fn[n] — over 40 built-in functions and 24 frame predicates. 10/12 test suites pass with zero crashes.

-- example.prima space math { fn[0] = double, }; pipe process(x) { x as number; -> fn[0] from math(x); output result; }; process(21);
