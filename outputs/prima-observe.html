Three primitives
as
Positive constraint
A value counts as X. The observer's collapse resolves it blue — and the resolution persists, briefly, after the gaze moves on.
not_as
Negative constraint
A value absolutely does not count as Y. The collapse resolves it orange — a definite exclusion, held until forgotten.
fn[n]
Categorical computation
Work selected by index from a function space. Gold — the suspended state where no function has yet been chosen.
Not a framework. Not a syntax. A decision that only happens — and the rest is the silence before it.
