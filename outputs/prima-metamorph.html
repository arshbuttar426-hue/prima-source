Three primitives
as
Positive constraint
A value counts as flowing. The line takes the wave function — horizontal strands, blue, continuous.
not_as
Negative constraint
A value absolutely does not flow. The line takes the burst function — radial, orange, divergent.
fn[n]
Categorical computation
Work selected by index from a function space. Gold — the lattice where structure crosses itself.
Not a framework. Not a syntax. A function that becomes a function — and the seam between them is the only honest line.
